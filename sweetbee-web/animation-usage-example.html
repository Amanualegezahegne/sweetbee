🎨 Animation Engine

GPU-Accelerated Animations with Reduced Motion Support

📖 About

The Animation Engine provides smooth, performant animations using GPU-accelerated CSS properties (transform and opacity). It includes support for reduced motion preferences and maintains a 60fps target.

Key Features:
  • ✓ GPU-accelerated (transform & opacity only)
  • ✓ 60fps target with requestAnimationFrame
  • ✓ Automatic reduced-motion support
  • ✓ Promise-based API for easy chaining
  • ✓ Configurable durations and delays

View and modify Animation Engine configuration:

🎛️ API Reference

// Available Methods: AnimationEngine.fadeIn(element, duration) // Fade in animation using opacity // Returns: Promise AnimationEngine.slideUp(element, duration, distance) // Slide up animation using translateY // Returns: Promise AnimationEngine.scaleUp(element, duration, fromScale, toScale) // Scale up animation using scale transform // Returns: Promise AnimationEngine.stagger(elements, animationFn, staggerDelay, duration) // Animate multiple elements with delay between each // Returns: Promise (resolves when all complete) AnimationEngine.getConfig() // Get current configuration object // Returns: Object with config values AnimationEngine.updateConfig(newConfig) // Update configuration values AnimationEngine.prefersReducedMotion // Boolean indicating user's motion preference
